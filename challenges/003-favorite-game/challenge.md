# 003: Favorite Game 🎮

**Concept:** variables (`let`) · **Difficulty:** ★☆☆☆☆

## Goal

Store the text `Mario Kart` in a variable, then return that variable.

## Description

A **variable** is a labeled box you can store a value in:

```js
let snack = "stroopwafel";
```

This makes a box labeled `snack` containing the text `"stroopwafel"`.
From then on, writing `snack` means "whatever is in that box".

Today: make a variable called `game`, put `"Mario Kart"` in it, and return
the variable (not the text directly, the point is to use the box!).

## Examples

| When you call    | It returns     |
| ---------------- | -------------- |
| `favoriteGame()` | `"Mario Kart"` |

## What the tests check

- returns "Mario Kart"
